# To The Light — M0

Godot 4.7.x, Forward+ / Vulkan. Откройте `project.godot` в редакторе и запустите основную сцену (F6/F5). Первый запуск импортирует ресурсы и строит процедурный рельеф, поэтому может занять время.

В этой промежуточной версии можно только осматриваться мышью; Esc отпускает/захватывает курсор, F переключает фонарь. Передвижения и рыбалки нет. Башня и мишень относятся к следующему этапу, M1.

Автопроверка после импорта: `JOURNEY_SMOKE=1 godot --headless --path .`. Она проверяет сборку сцены, рельеф, песок, звук, камеру, отсутствие управляющих действий движения и смену времени. Headless не проверяет Vulkan и шейдеры: требуется также обычный запуск на машине с Vulkan. История изменений — в `CHANGELOG.md`.
