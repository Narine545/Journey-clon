# To The Light — M1

Godot 4.7.2, Forward+ / Vulkan. Откройте `project.godot` в редакторе и запустите проект (F5). Первый запуск импортирует ресурсы и строит процедурный рельеф, поэтому может занять время.

## Управление

- **WASD / стрелки** — ходьба только по площадке башни. Сойти или спрыгнуть нельзя.
- **Мышь** — осмотреться. Камера изначально направлена на неподвижную мишень внизу.
- **Esc** — отпустить / захватить курсор; левый клик также возвращает захват.
- **F** — фонарь.

Радио, крепление винтовки и лифтовая шахта пока декоративные; стрельба и доставка появятся на следующих этапах. Код воды сохранён для будущих задач, но не подключён к сцене.

Проверка после импорта: `JOURNEY_SMOKE=1 godot --headless --path .`. Дополнительно CI запускает Forward+ на программном Vulkan и сохраняет кадр башни. Это не заменяет проверку звука, изображения и производительности на реальной машине. История изменений — в `CHANGELOG.md`.
