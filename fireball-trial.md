# Огненный носовой снаряд — визуальное сравнение

В HUD рейда добавлен «ОГНЕННЫЙ НОС · СРАВНЕНИЕ» ниже переключателя эффектов, отдельно от тестов сфер. Изначально включён, настройка сессионная, не помечает рейд debug. Выключение либо отключение «ЭФФЕКТЫ» возвращает штатные носовые снаряды. Борты и вражеские снаряды не изменены; гарпун-пробитие остаётся прежней механикой с тем же визуальным тестом огня.

`RaidFireballs` использует один QuadMesh MultiMesh на SHOT_CAP, без узла/источника света на выстрел. Из существующего списка берутся только дружественные носовые снаряды. Старый mesh для них уменьшается до 0.001, остальные рисуются штатно. Размер эффекта 2.2×0.9 м включает хвост, это не hitbox. Яркая голова совмещена с интерполированной точкой снаряда, хвост позади. Ось плоскости — проекция фактической скорости на плоскость камеры: корректно при смене курса и повороте осмотра, без отдельного viewport. Обычная depth-проверка сохранена, тени выключены; запись глубины выключена, blend_mix вместо additive. Ограниченная emission 0.45 без локального света, стоимость/яркость на GPU не измерены.

Адаптированы шумы пользовательского Fireball shader Muhammad Mujtaba / MIT; форма головы/хвоста специализирована под 3D. Три noise-октавы вместо четырёх fbm-проходов исходника. Обратных smoothstep нет. Время берётся из raid.elapsed, а не shader TIME: на паузе рябь огня не продолжает жить. Урон, скорость, collision/hit radius, лимиты попаданий, статистика и график стрельбы не менялись. На start/leave batch очищается, за пределами engaged не обновляется.

65 Python-проверок, parser изменённых скриптов, lint нового helper и diff-check проходят. Godot отсутствует: движковая типизация/shader-компиляция, прозрачная сортировка с водой, яркость ночью и видимость при zoom-out ещё не проверены. Сравнить при развороте лодки, разных курсах, гарпуне/пробитии, включении/выключении FX и на паузе. Это не обещание пиксельного совпадения с исходным canvas shader.

Частицы inward/outward для сфер, постоянный boss HP/direction cue и баланс оружия в этот этап не включены.
