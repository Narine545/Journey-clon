# Огненный носовой снаряд — визуальное сравнение

В HUD рейда добавлен «ОГНЕННЫЙ НОС · СРАВНЕНИЕ» ниже переключателя эффектов, отдельно от тестов сфер. Изначально включён, настройка сессионная, не помечает рейд debug. Выключение либо отключение «ЭФФЕКТЫ» возвращает штатные носовые снаряды. Борты и вражеские снаряды не изменены; гарпун-пробитие остаётся прежней механикой с тем же визуальным тестом огня.

`RaidFireballs` использует один QuadMesh MultiMesh на SHOT_CAP, без узла/источника света на выстрел. Из существующего списка берутся только дружественные носовые снаряды. Старый mesh для них уменьшается до 0.001, остальные рисуются штатно. Размер эффекта 2.2×0.9 м включает хвост, это не hitbox. Яркая голова совмещена с интерполированной точкой снаряда, хвост позади. Ось плоскости — проекция фактической скорости на плоскость камеры: корректно при смене курса и повороте осмотра, без отдельного viewport. Обычная depth-проверка сохранена, тени выключены; запись глубины выключена, blend_mix вместо additive. Ограниченная emission 0.45 без локального света, стоимость/яркость на GPU не измерены.

Адаптированы шумы пользовательского Fireball shader Muhammad Mujtaba / MIT; форма головы/хвоста специализирована под 3D. Три noise-октавы вместо четырёх fbm-проходов исходника. Обратных smoothstep нет. Время берётся из raid.elapsed, а не shader TIME: на паузе рябь огня не продолжает жить. Урон, скорость, collision/hit radius, лимиты попаданий, статистика и график стрельбы не менялись. На start/leave batch очищается, за пределами engaged не обновляется.

65 Python-проверок, parser изменённых скриптов, lint нового helper и diff-check проходят. Godot отсутствует: движковая типизация/shader-компиляция, прозрачная сортировка с водой, яркость ночью и видимость при zoom-out ещё не проверены. Сравнить при развороте лодки, разных курсах, гарпуне/пробитии, включении/выключении FX и на паузе. Это не обещание пиксельного совпадения с исходным canvas shader.

Частицы inward/outward для сфер, постоянный boss HP/direction cue и баланс оружия в этот этап не включены.

## Чуть крупнее и направленные частицы сфер

По пользовательской проверке огненный нос принят, размер увеличен на 25%: quad теперь 2.75×1.125 м. Смещение центра пересчитано с 0.55 на 0.6875 м, так что яркая голова остаётся в точке штатного снаряда. Collision/damage не увеличены.

Добавлен `RaidFieldParticles`: общий аналитический MultiMesh на 160 мягких искр, по 20 на поле (расчёт на debug cap4 каждого типа). В обычной игре максимум 40. Бирюзовые расходятся наружу, фиолетовые появляются во внешней части и по спирали уходят к центру; в механической фазе выброса последних 0.4 с — один синхронный разлёт наружу. Появление/исчезновение искр плавное, привязано к возрасту и duration-снимку конкретной мины. Это отдельный визуальный слой над водой, не новые импульсы/урон/изменение сил.

Движение вычисляется аналитически из того же возраста, который обновляет физика мин, не shader TIME, поэтому на паузе не продолжается. Выключение «ЭФФЕКТЫ» и режим осмотра скрывают batch; оболочки и механика остаются прежними. После возврата FX искры показывают актуальную фазу, старые хвосты не накапливаются. Пул очищается при start/leave, без новых узлов/источников света на искру. Обычные depth test/blend_mix, без screen texture/нового viewport. Shader только мягкая точка с ограниченной emission.

Это независимая упрощённая реализация идеи inward/outward, **не импорт Particle Process v2**. Универсальный turbulence/collision/curve процессор из присланного кода не включался. Авторство его upstream кода не присваивается; источник остаётся reference-only в SHADER-CREDITS.

66 Python-проверок, parser трёх изменённых GDScript, lint новых/изменённых helpers и diff-check проходят. Godot отсутствует: shader compile, видимость точек при zoom-out, прозрачная сортировка с оболочкой/водой и GPU-cost ещё требуют пользовательского прогона. Постоянный boss cue в этот этап не входит.

## Огненные бортовые снаряды

По запросу пользователя фильтр визуального batch расширен на дружественные NOSE и SIDES. Картечь и её эволюция используют ту же ориентацию по фактической скорости каждого снаряда. Вражеские выстрелы не изменены. Общий пул остаётся SHOT_CAP, дополнительных экземпляров поверх лимита выстрелов нет; при картечи прозрачных огненных quad одновременно больше, GPU-cost не измерен. Переключатель переименован в «ОГНЕННЫЕ СНАРЯДЫ · ТЕСТ», единый fallback на старый вид для обоих орудий. Урон/пробитие/скорость/попадания не менялись.

В RaidFieldParticles локальный seed переименован в particle_variation, чтобы убрать SHADOWED_GLOBAL_IDENTIFIER. Визуал искр намеренно пока не дорабатывался. 66 Python-проверок, parser изменённых скриптов, lint двух helpers и diff-check проходят; движковый/визуальный тест недоступен.
