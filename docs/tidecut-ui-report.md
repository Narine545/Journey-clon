# TIDECUT — редизайн интерфейса: что сделано и чем пришлось заменить

Стиль: **Persona 5 по принципам** (плоские фигуры, рваные срезы, диагональная
типографика, агрессивный overshoot) × **море** (изобаты, гравюра, сигнальные
флаги, качка, глубина). Ни одного ассета, шрифта или цвета из Persona 5 не
взято: только принципы композиции.

База — 1920×1080. Весь интерфейс в авторских координатах 1920×1080, на любое
окно переносится единым масштабом (`TideStage`). Все тексты — по-русски.

## 1. Из чего собран стиль

| Слой | Файл | Что делает |
| --- | --- | --- |
| Токены | `scripts/ui/tide_tokens.gd` | 5 цветов, шрифты, шаги зубцов, тайминги, helper'ы alpha/clock |
| Геометрия | `scripts/ui/tide_shapes.gd` | рваный прямоугольник с зубцами, пластина, вымпел, силуэт корпуса, звено цепи, контур флага, гравюрная штриховка |
| Движение | `scripts/ui/tide_fx.gd` | появление панелей, брызги, hit-stop, качка, заголовки |
| Качка | `scripts/ui/tide_bob.gd` | синус ±0.5–1.2°, период 2.4–3.2 с, своя фаза у каждого блока |
| Сцена | `scripts/ui/tide_stage.gd` | единый масштаб 1920×1080 на любое окно |
| Кит | `scripts/ui/tide_kit.gd` + `scenes/ui/kit/*.tscn` | фабрики: PanelTorn, Flag, ChainBar, Stamp, TitleLabel, Porthole, Button, IsobathBackdrop, WaveWipe |
| Тема | `assets/ui/tide_theme.tres` | Oswald по умолчанию, кнопки/чекбоксы — без стокового вида |
| Шрифты | `assets/fonts/` | Unbounded Black (заголовки), Oswald Medium (текст), JetBrains Mono ExtraBold (цифры) — все с кириллицей, OFL рядом |

Палитра ровно пять цветов и только плоские заливки:
`#0D1520` ink, `#1B3A5C` deep, `#EFEAD8` foam, `#E3212E` flare, `#35D0BA` sonar.
Серый отсутствует: приглушение — это `foam` с alpha 0.30–0.45.

## 2. Пять фирменных приёмов

1. **Зубцы-волна по кромке** — `TideShapes.torn_rect`: шаг 14–22 px, высота
   6–10 px, по нижней кромке ключевых панелей (титул, рапорт, журнал, HUD-плиты).
2. **Изобаты вместо полутоновой сетки** — `shaders/isobaths.gdshader`:
   концентрические контуры с пологим сдвигом, шаг 32–38 px, alpha 0.06–0.09.
3. **HP = осадка корпуса** — `shaders/water_fill.gdshader` + `TideHullGauge`:
   вода поднимается по силуэту лодки, на ватерлинии плоская пенная кромка;
   ниже 25 % вода краснеет (flare) и пульсирует.
4. **Выбор апгрейда = три сигнальных флага** — `TideFlag`: прямоугольный,
   треугольный и вымпел с вырезом «ласточкин хвост». Наведение поднимает флаг
   и пригибает соседей, выбор — «поднять флаг»: рывок вверх с брызгами.
5. **Качка** — `TideBob`: каждый крупный блок качается ±0.5–1.2°, период
   2.4–3.2 с, у блоков разные фазы, поэтому композиция «дышит», а не качается
   целиком.

## 3. Экраны

### 3.1 «ПОПУТНЫЙ ВЕТЕР» — повышение уровня (`scripts/ui/screens/upgrade_screen.gd`)
Рваный титульный блок под −7°, рваные обрывки карт по краям, красный штамп
уровня «05 → 06», три флага разной формы с плашками превью, кнопка
«ПЕРЕБРОСИТЬ», штамп «ПОВЫШЕНИЕ» на выборе. Тексты подгоняются под полотно
флага по самому длинному слову, поэтому кириллица не вылезает и не обрезается.

### 3.2 Боевой HUD (`scripts/ui/screens/hud_tide.gd`)
Осадка корпуса (вода в силуэте + риски 25/50/75), якорная цепь опыта во всю
ширину сверху, иллюминатор-таймер с восемью заклёпками, штамп-счётчик добычи,
сонар, лента прочности крупной цели, блок такелажа. Каждый блок повёрнут на
2–6° и качается в своей фазе.

### 3.3 «СУДОВОЙ ЖУРНАЛ» — пауза (`scripts/ui/screens/pause_journal.gd`)
Страница пены с гравюрной штриховкой, зубцами и красным оттиском-подложкой.
Записи вахты: моно-время, название, метка «ЭВОЛЮЦИЯ»; на свежей записи стоит
штамп «ЗАЧТЕНО» (остаётся на странице). Кнопки «ПРОДОЛЖИТЬ» (sonar) и
«В МЕНЮ» (контур flare), блок отладочных тумблеров.

### 3.4 «ПРОПАЛ БЕЗ ВЕСТИ» — итог рейда (`scripts/ui/screens/game_over_report.gd`)
Телеграмма-рапорт: двойная рамка (deep-подложка + пена с красным оттиском),
заголовок flare под −11°, кикер, вердикт, протокол моноширинным с точками-
выносками, колонка «СБОРКА», блок последних записей, штамп «SOS» (или
«ЗАЧТЕНО» при победе), кнопки «НОВАЯ ВАХТА» и «В МЕНЮ». Появление — «нырок»
сверху кубической кривой с ударом штампа и тряской камеры 4 px.

### 3.5 Главное меню (`scripts/ui/screens/main_menu.gd`)
Афиша: живая остановленная 3D-сцена за рваными панелями, титул «К СВЕТУ»,
кикер, маршрут, три флажка-кнопки (solid / контур / ghost) с брызгами при
появлении, штамп «ОТХОД 06:00», внизу моно-строка «РЕЙС №041 · ВЕРСИЯ 0.9.4 ·
TIDECUT UI KIT». Меню встроено в `boat_main.gd`: Esc открывает/закрывает,
«НОВАЯ ВАХТА» запускает рейд, «В МЕНЮ» закрывает, «ВЫХОД» завершает игру.

## 4. Движение

| Требование | Реализация |
| --- | --- |
| Появление панели: scale 0.5→1 + поворот от −10°, 0.14–0.26 с, TRANS_BACK/EASE_OUT | `TideFx.pop_in()` / `TideFx.appear()` |
| Наведение: сдвиг 4 px + усиленный наклон, 0.09 с EASE_OUT | `TideButton._on_enter()` |
| Нажатие: scale 0.93 / 0.06 с, затем отскок TRANS_BACK | `TideButton._pressed()` |
| Качка: синус ±0.5–1.2°, 2.4–3.2 с | `TideBob` |
| Переходы волной 0.30–0.40 с через шейдер-маску | `shaders/wave_wipe.gdshader` + `TideWaveWipe.cover_then()` |
| Тряска от урона 4–6 px / 0.12 с | `TideFx.shake()` |
| Hit-stop 0.08 с + искры на цепи | `TideFx.freeze()`/`unfreeze()` (таймер с `ignore_time_scale`), `TideChainBar.spark()` |
| 8–16 брызг пены на появление панели, жизнь 0.3–0.5 с | `TideFx.splash()` (CPUParticles2D, плоские квадратные капли) |

Запрещено и не используется: LINEAR на появлениях, фейды дольше 0.5 с,
градиенты, блюр, мягкие тени, радиусы скругления больше 2 px.

## 5. Замены и отступления (флаги!)

Всё, что пришлось заменить на аналог в том же стиле:

* **Шрифты Persona 5 → Unbounded / Oswald / JetBrains Mono.** Копировать
  гарнитуры нельзя; Unbounded Black даёт ту же «плакатную» плотность капса,
  JetBrains Mono ExtraBold — технику цифр, Oswald Medium — текстовый набор.
* **Полутоновая сетка (halftone) → изобаты.** Прямо по брифу: вместо растровых
  точек — концентрические контуры глубин.
* **Фотографическая цепь XP → звенья-«стадионы»** (`TideShapes.stadium`):
  плоские скруглённые звенья без единого радиуса больше 2 px, потому что
  «скругление» — это геометрия звена, а не UI-кнопки.
* **Спрайтовые брызги и искры → CPUParticles2D с квадратными каплями без
  текстуры** (в проекте нет бинарных ассетов, кроме .ttf).
* **Полотно флага: скелет/сетка → вершинный шейдер `flag_wave.gdshader`.**
  Контур вымпела/треугольника нарезан по кромке (шаг ~13 px), поэтому волна
  гнёт силуэт плавно, а не «лесенкой» из ячеек сетки.
* **Рваная бумага рапорта → полигоны + штриховка линиями.** Никаких текстур
  бумаги: срез, оттиск и гравюра считаются кодом.
* **«Глубина» под меню → живая 3D-сцена за панелями**, а не картинка: меню
  висит поверх остановленной игры (`CanvasLayer` 50 в `boat_main.gd`).
* **Волновой переход между экранами** сделан шейдером-маской на весь экран, а
  не заготовленной анимацией: маска одна, «гребень» двигается кодом.

Отклонений от брифа по палитре, сетке и типографике нет.

## 6. Проверки

* `godot --headless --import` — без `SCRIPT ERROR` / `Parse Error`.
* `JOURNEY_SMOKE=1` (автотест геймплея) — зелёный.
* `JOURNEY_BOAT_SMOKE=1` — зелёный; проверки UI переписаны на `TideUi`
  (`_chain`, `_hull`, `_report_payload()`, `report.open()`).
* Витрина `res://scenes/ui/showcase.tscn` под xvfb + Vulkan (lavapipe)
  снимает `shots/tide_01…06_*.png` — это и есть скриншоты сдачи.

Два теста в `scripts/boat_smoke.gd` пришлось починить — они были добавлены
коммитом с `[skip ci]` и ни разу не запускались:

1. «отмель под прицепом»: плашкоут ставился на 12 м мористее буя, где глубина
   3.2 м при пороге 2.8 м, — тест не мог пройти физически. Теперь плашкоут
   ставится на буй-маркер изобаты (2.25 м).
2. «вспышка сохраняет яркую фазу»: проверялись instance-трансформы MultiMesh,
   которых в headless (dummy-рендерер) не существует — читались нули. Теперь
   проверяются яркая фаза, приоритет рисования и выкладка шести квадов.

## 7. Что осталось

* Экран 3.5 в живой игре показывает настоящую 3D-сцену; в витрине за панелями
  синтетическое море (витрина не поднимает рейд).
* Витрина — единственный источник скриншотов; отдельные «боевые» кадры HUD
  в витрине кормятся фиктивным состоянием (см. `TideShowcase._hud_state()`).
* `validate.yml` разведён на три параллельные задачи (`headless`, `ui`,
  `render`): программный рендер под lavapipe не укладывался в один лимит
  25 минут.
