# Звуки моря: как их послушать

В игре звука нет ни одним файлом: всё синтезируется кодом при запуске
(`scripts/boat_sound.gd`), как и на берегу в `scripts/audio.gd`.

Файлы в этой папке — превью того же синтеза, посчитанные отдельным скриптом
на Python: те же формулы, огибающие и фильтры, только иначе устроенный
генератор шума. То есть это не сами игровые сэмплы, а их близкий слепок —
чтобы можно было послушать и сказать, что не так, не запуская игру.

| Файл | Что это | Уровень в игре |
| --- | --- | --- |
| `orb_splash.wav` | всплеск сферы: шлепок воды и низкий удар | −6…−11 дБ, позиция сферы |
| `orb_under.wav` | глухой «буль», когда сфера ушла под воду | −11 дБ |
| `orb_rise.wav` | свист вверх при рывке из воды в небо | −9 дБ |
| `sea_loop.wav` | тихий фон моря, петля 4 с | −23 дБ, всегда |
| `wash_loop.wav` | шум воды под днищем, петля 1,6 с | −32…−15 дБ по скорости |
