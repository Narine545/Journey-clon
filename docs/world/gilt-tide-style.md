# Экранный слой «Золочёный прилив»

`scripts/gilt_style.gd` и `shaders/gilt_style.gdshader` — отдельный
экранный цветовой слой мира с управлением интенсивностью клавишей C.
Он не задаёт архитектуру посёлка и не меняет оформление интерфейса TIDECUT.

Готические постройки и декоративный реквизит из прежнего варианта посёлка
удалены из активной расстановки. Актуальное устройство, масштаб и соглашения
для замены домов описаны в `harbor_village.md`.
