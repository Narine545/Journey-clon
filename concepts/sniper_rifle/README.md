# Фантастическая винтовка — отдельный концепт

Черновая модель с оптикой для осмотра и правок в Blender; в игровую сцену не добавлена и её механика не меняется.

- `scifi_sniper_concept.blend` — исходник Blender: детали разнесены по объектам и материалам в коллекции `RIFLE - editable parts`. Скругления оставлены редактируемыми модификаторами. Студийное освещение, камера и подложка находятся отдельно в `STUDIO - hide for modelling`.
- `scifi_sniper_concept.glb` — экспорт только геометрии оружия с применёнными скруглениями, без камеры и студии; будущую интеграцию и положение в руках нужно будет согласовать отдельно.
- `scifi_sniper_preview.png` — предварительный рендер модели.

Приблизительная общая длина — 1,63 м, единицы Blender — метры. Это стилизованный концепт, не финальный дизайн, нет авторских текстур, рук, рига или анимации. Форма и пропорции требуют оценки пользователем.

Модель создаётся из геометрических примитивов скриптом `tools/create_scifi_rifle.py`; внешний код и 3D-ассеты не использованы. Пересоздание скриптом перезапишет файлы модели, поэтому пользовательские правки сначала нужно сохранить отдельно.
