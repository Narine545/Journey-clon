# Артефакты из другого мира

Сюда кладутся трёхмерные модели находок:

- `cyber_orb.glb` — сфера, точка входа в рейд (плавает в океане);
- `food_collection_-_game_ready.glb` — приз, который показывает рапорт после победы.

Игра ищет файлы по имени в `assets/artifacts/`, `assets/models/`, `assets/` и в корне
проекта. Пока файла нет, вместо модели рисуется временная заглушка из примитивов.
Масштаб и центр подгоняются автоматически, готовить модель под размер не нужно.
