# Записи для радио

Короткие оригинальные записи изготовлены для прототипа локальным синтезом eSpeak NG (русский голос, обработка под узкую радиополосу). Это синтетическая речь, не запись реального человека. В проекте лежат только результат WAV, не программа и не библиотека eSpeak NG. Источник инструмента: https://github.com/espeak-ng/espeak-ng (GPL-3.0-or-later).

- `post.wav`: «Запись поста три. Ветер стихает. Если кто-нибудь слышит, берегите тишину».
- `weather.wav`: «Архив прогноза. Песок смещается к востоку. Наблюдение продолжается».

- `beacon.wav`: «Всем машинам. Сигнал маяка активен. Следуйте к источнику». Это синтетическая речь для повторяющейся передачи маяка.
